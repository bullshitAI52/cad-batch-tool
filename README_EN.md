# CAD Batch Tool

CAD Batch Tool automates common AutoCAD DWG tasks: working on independent copies, cleaning layers, performing limited explode rounds, counting blocks, and converting DWG files to older formats.

## Basic use

1. Read the Chinese guide or script comments before running.
2. Put the DWG files in the input folder.
3. Run `Run-CAD.cmd` or `Run-CAD.ps1`.
4. Check the output folder and the generated log.

The tool is intended to protect the original drawings by processing copies. Test it on sample files first; real-machine AutoCAD/ODA compatibility should be verified before batch use.
