# 独立 CAD 块数量统计工具

只读统计图纸中的 INSERT 块引用，导出 Excel（.xlsx）和 CSV。不炸开、不清理、不修改原图，也不启动 AutoCAD。可独立下载此目录使用，不依赖仓库里的其他脚本。

## 使用

### 图形界面（推荐）

首次安装 Python 和 ODA 后，运行一次 `Setup.cmd`，然后双击 **`Start-UI.cmd`**：

1. 选择 CAD 文件夹，可勾选是否扫描子文件夹。
2. 选择 Excel/CSV 结果保存文件夹。
3. 如 ODA 未被自动发现，选择 ODA 程序文件；分类配置和位置容差也可在界面调整。
4. 点击「开始统计」，查看当前文件、读取/转换、统计、去重和导出阶段及日志。
5. 完成后点击「打开结果文件夹」。

界面在后台线程运行任务，不在界面线程处理图纸。进度前 95% 按已完成文件数计算，剩余部分为导出；不是按文件大小或预计耗时计算，单张大图转换时百分比不会持续增长。失败文件也计入已处理份数，最终状态单独列出失败/警告数量。

「处理完当前文件后停止」不会强行中断 ODA，会在当前图纸结束后导出已处理部分，并注明未处理数量。当前文件转换卡住时仍需要等待，运行中不会直接关闭窗口。

目录扫描目前包含所有 DWG/DXF，包括已有副本；请把需要统计的原图放在单独文件夹，避免把备份副本也选入。Excel 输出不会被再次当作图纸。

需要 Python 的 Tkinter 支持（Windows 官方 Python 安装通常自带）。Mac 可运行 `python gui.py`，但 Windows 启动脚本、ODA 安装路径和 DWG 转换仍需在目标电脑验证。

### 命令行与拖放

1. 安装 Python 3.10+。DWG 还需安装 [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter)；DXF 无需转换器。
2. 双击 `Setup.cmd` 安装依赖。
3. 将一张或多张 DWG/DXF 拖到 `Count-Blocks.cmd`；或双击它，弹窗选择图纸。
4. 第一张图纸旁的「块统计结果」目录生成 Excel、统计 CSV 和处理记录 CSV。每次运行使用独立文件名。

Excel 默认包含「分类去重统计」「块数量统计」「处理记录」「重复位置明细」四张表，并输出对应统计/记录 CSV。不同文件的同名块不合并，避免不同块定义被混为一谈。

## 分类与重叠去重

默认开启，只处理统计结果，不删除原图对象。

- 「分类去重统计」列出原始直接/嵌套数量、各自重复份数、去重后数量和疑似重复组数。父组件与内部零件不能盲目相加当作设备总量。
- **确认重复**：同一文件、布局、有效图层、直接/嵌套口径内，同一普通块定义的世界变换矩阵、属性及父级显示上下文完全相同，只保留一份。比较是严格数值比较，浮点差异可能导致保守漏判，不会按位置容差直接扣除。
- **疑似重复**：同名块位置接近，或不同块名但支持的基础图形结构指纹相同且位置接近。旋转、缩放、属性不同也可能出现在此表，均不自动扣减。
- 嵌套块按各级变换计算世界坐标，包含块基点、旋转、缩放、阵列偏移；层级和父级上下文不同的实例可能保守地保留，不宣称完全几何去重。
- 原始匿名/动态块、外参、未知内容、扩展信息等不做自动扣除。不同名称的比较仅支持 LINE/CIRCLE/ARC/LWPOLYLINE/POINT/SOLID/3DFACE 组成的基础块结构，不是通用图形相似识别，也不识别散线拼出的灯具。
- 「重复位置明细」包含组号、判定、文件、布局、图层、块名、父级对象句柄路径、阵列序号和 XYZ。坐标指块基点世界坐标，不是包围盒中心。原始 DWG 经 ODA 转换后句柄可能变化，应结合坐标核对。
- 疑似组按邻近关系连接，组首和组尾不一定在容差以内；确认重复组保留项可以同时出现在疑似组中，不重复扣除。
- 默认容差 `0.1`，使用**图纸坐标单位**：毫米图为 0.1 毫米，米图为 0.1 米。它仅影响疑似检测，请按项目修改 `--tolerance`，不要把默认值当作统一施工精度。
- 展开超过十万个实例或重叠候选比较超过一百万次时，不输出该文件的去重结论，保留基础计数并在处理记录标明失败。循环引用/深度超限会明确警告数量不完整。

### 灯具、道具分类配置

编辑同目录 `classification.json`。默认只有「块名含灯」「图层含灯具」「块名含道具」「图层含道具」的示例关键词规则，匹配结果需人工核对；匹配不到就是「未分类」，不会把全部同层对象自动当成同种设备。

`block` 与 `layer` 都支持 `*` 通配符，两项同时匹配才生效，从上到下使用第一条规则。例如把实际块名 `TD-01` 匹配到灯具：

```json
{"category": "灯具", "block": "TD-*", "layer": "照明*"}
```

名称完全不规范时需要先查看原始块名表，配置映射后再运行；本工具不保证仅靠名称自动识别真实设备类型。

## 统计口径

- **直接数量**：模型空间或布局直接放置的块实例数。
- **嵌套数量**：块内部的子块引用，乘以各级父块的数量。例如 3 个组件各含 2 个螺栓，组件直接数量为 3，螺栓嵌套数量为 6。两列不可不分块名就相加作为设备总量。
- 阵列块按行列及间距展开计数，零间距的重叠阵列位置按一个位置计算，与 ezdxf 的 multi_insert 规则一致；不实际复制图形。
- 默认遍历模型及全部布局，包括隐藏对象和关闭/冻结图层。布局中的视口不额外重复计算其显示的模型图形。
- 嵌套块在 0 图层时继承父块的有效图层。
- 外参只计引用次数，不进入外部文件；缺失块定义、循环引用、深度或遍历上限会在处理记录里警告。
- 匿名/动态块保留原始名称（如 *U123），不会自动识别或合并有效块名。代理对象或未以 INSERT 表示的对象不作为块数量统计。
- 循环引用及深度超过 32 层的分支停止，默认最多遍历十万个引用节点；出现警告须检查是否数量不完整。
- 本工具不识别散线拼出的设备。只有图纸按块绘制时，块数量才可能对应实际设备数量。

## 参数

```powershell
.\.venv\Scripts\python.exe .\block_count.py --scope model --no-nested 'D:\图纸\示例.dwg'
.\.venv\Scripts\python.exe .\block_count.py --oda-path 'C:\Program Files\ODA\ODAFileConverter\ODAFileConverter.exe' --output-dir 'D:\统计结果' 'D:\图纸\一.dwg' 'D:\图纸\二.dxf'
.\.venv\Scripts\python.exe .\block_count.py --tolerance 0.01 --rules '.\classification.json' 'D:\图纸\示例.dxf'
.\.venv\Scripts\python.exe .\block_count.py --no-dedup 'D:\图纸\示例.dxf'
```

CSV 使用 UTF-8 BOM，方便 Excel 显示中文。可疑公式前缀的名称在 CSV 中加单引号保护；XLSX 中保留原名称并明确存为文本。

当前十二项测试覆盖程序生成的 DXF 样图、完全重复与疑似重复、属性差异、旋转/缩放/基点、嵌套阵列、空间隔离、负坐标边界及 Excel/CSV 读回核验。真实 DWG 的 ODA 转换仍需在安装了转换器的电脑上验证，不能据此保证所有专业图纸的统计准确性。
